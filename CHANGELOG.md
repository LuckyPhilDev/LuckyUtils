## [1.0.0] - 2026-04-12

### Added
- **LuckyUI** — dark/gold colour palette, font constants, and frame builders: styled panels, headers, buttons, checkboxes, and dividers. Includes `EnableDrag` for drag-to-move frames with automatic position persistence.
- **LuckySettings** — fluent builder API for Interface Options panels: toggles, selectors, sliders, and section headings.
- **LuckyMinimap** — draggable minimap buttons with position and visibility persistence, no external library required.
- **LuckyLog** — gated debug loggers that only print when an addon's debug flag is enabled.
- **LuckyDeps** — optional dependency checking with version validation.
- **LuckySound** — helpers for playing addon sound files and built-in WoW sound kit entries.
- **LuckyUtils** — general utilities: `ApplyDefaults` for recursive SavedVariables initialisation, and `CharacterKey` for a canonical `Name-Realm` character identifier.
